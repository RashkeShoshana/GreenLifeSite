# Green Life - Caring for the Environment

## Project Overview

"Green Life" is a website dedicated to promoting environmental awareness and sustainable living. The website provides educational resources, articles, and actionable tips to help individuals and communities protect the environment.
---
## Features

- **Informative Articles**: Learn about recycling, solar energy, ecological gardening, and green pest control.
- **Navigation Menu**: Easy access to different topics, including contact information and an "About Us" section.
- **Interactive Layout**: Engaging design with images, articles, and a clean user experience.
- **Contact Us**: Easily get in touch via phone or email.
---
## File Structure

```
project-directory/
├── images/ # Contains images used in the website
├── pageStyle.cs # Contains additional HTML pages
├── style.css # Styling for the website
├── index.html # Main HTML file
└── README.md # Project documentation
```

### Main Files

- **index.html**: The main homepage of the website.
- **style.css**: The CSS file that handles the styling and layout of the site.
- **images/**: Contains all the images used in the project, including logos, topic images, and decorative elements.
- **pageStyle.css**: Additional pages for topics like recycling, solar energy, ecological gardening, and more.

---

## Getting started

### Prerequisites

Ensure you have a browser and basic knowledge of HTML and CSS.

### How to Run the Project

1. Clone the repository:
 ```bash
 git clone https://github.com/your-username/green-life.git
 ```

2. Open the `index.html` file in your browser:
 ```bash
 open index.html
 ```
